ឯកសារណែនាំផ្លូវការ — ខ្មែរចារ (KhmerChar)

ខ្មែរចារ (KhmerChar) គឺជាភាសាប្រូក្រាមីងកម្រិតខ្ពស់ដែលត្រូវបានរចនាឡើងជាមួយវាក្យសព្ទ និងពាក្យគន្លឹះជាភាសាខ្មែរពិតប្រាកដ។ វាផ្ដល់នូវភាពងាយស្រួលក្នុងការសិក្សា សរសេរកូដតាមបែប Object-Oriented Programming (OOP) និងគាំទ្រលេខខ្មែរ (០-៩) ដោយផ្ទាល់។

🚀 ចាប់ផ្តើមរៀនឥឡូវនេះ 🎮 សាកល្បងកូដលើ Web Browser

សេចក្តីផ្តើម (Introduction) #

ខ្មែរចារ (KhmerChar) ត្រូវបានបង្កើតឡើងដើម្បីកាត់បន្ថយរបាំងភាសាក្នុងវិស័យវិទ្យាសាស្ត្រកុំព្យូទ័រនៅកម្ពុជា។ សិស្ស និស្សិត និងអ្នករៀនដំបូងអាចយល់ច្បាស់អំពីតក្កវិជ្ជានៃកូដ (Logic) តាមរយៈការប្រើពាក្យខ្មែរធម្មជាតិ ដូចជា តាំង, បង្ហាញ, បើ, ខណៈ, ថ្នាក់ និង អនុគមន៍។

💡
ចំណុចពិសេស៖ រាល់កូដឧទាហរណ៍ទាំងអស់ក្នុងឯកសារនេះ អ្នកអាចចុចប៊ូតុង ▷ រ៉ាន់កូដ (Run) ដើម្បីដំណើរការកូដ និងទស្សនាលទ្ធផលជាក់ស្ដែងលើ Browser បានភ្លាមៗដោយមិនបាច់ដំឡើងអ្វីទាំងអស់!

ការដំឡើង & ការចាប់ផ្តើម (Installation & Setup) #

ការចាប់ផ្តើមសរសេរកូដជាមួយ ខ្មែរចារ (KhmerChar) មានភាពងាយស្រួល និងរហ័ស។ អ្នកប្រើប្រាស់អាចជ្រើសរើសការដំឡើងតាមរយៈ Command Line Tool (CLI) សម្រាប់ដំណើរការលើម៉ាស៊ីនផ្ទាល់ ឬប្រើប្រាស់កម្មវិធី Khmer IDE ដោយមិនចាំបាច់ដំឡើងអ្វីទាំងអស់។

១. តម្រូវការប្រព័ន្ធ (Prerequisites)

មុនពេលចាប់ផ្តើមដំឡើង សូមប្រាកដថាម៉ាស៊ីនរបស់អ្នកមានលក្ខខណ្ឌដូចខាងក្រោម៖

  • ប្រព័ន្ធប្រតិបត្តិការ៖ គាំទ្រ macOS, Linux, និង Windows (WSL / PowerShell)
  • Dart SDK (3.0+)៖ សម្រាប់ដំណើរការ Engine និង Native Compiler របស់ភាសា
  • Git៖ សម្រាប់ទាញយកប្រភពកូដ ឬ Releases

២. ការដំឡើង CLI សម្រាប់អ្នកប្រើប្រាស់ទូទៅ (Universal One-Line Install)

អ្នកប្រើប្រាស់គ្រប់រូបអាចដំឡើង khmer CLI លើម៉ាស៊ីនរបស់ខ្លួនដោយផ្ទាល់តាមរយៈពាក្យបញ្ជាតែមួយបន្ទាត់៖

អថេរ និងប្រភេទតម្លៃ (Variables & Data Types) #

នៅក្នុងភាសាខ្មែរ យើងប្រើពាក្យគន្លឹះ តាំង (Let) ដើម្បីប្រកាសអថេរ។ អថេរក្នុង ខ្មែរចារ (KhmerChar) គឺ dynamic-typed មានន័យថាអ្នកអាចផ្ទុកទិន្នន័យជា លេខ, អក្សរ (String), Boolean, ឬ Null បានដោយសេរី។

  • លេខ (Numbers): គាំទ្រទាំងលេខអារ៉ាប់ (10, 3.14) និងលេខខ្មែរ (១០, ៣.១៤)។
  • អក្សរ (Strings): សរសេរនៅចន្លោះសញ្ញាសម្រង់ "..." ឬ '...'។
  • ប៊ូលីន (Booleans): ប្រើពាក្យគន្លឹះ ពិត (True) និង មិនពិត (False)។
  • ទទេ (Null): ប្រើពាក្យគន្លឹះ ទទេ សម្រាប់តម្លៃដែលគ្មានទិន្នន័យ។
KHMERvariables.khmer
# ប្រកាសអថេរផ្សេងៗ
តាំង ឈ្មោះ = "វ៉េងឈួង"
តាំង អាយុ = ២១
តាំង ជាសិស្ស = ពិត
តាំង ការងារ = ទទេ

បង្ហាញ("ឈ្មោះ:", ឈ្មោះ)
បង្ហាញ("អាយុ:", អាយុ)
បង្ហាញ("ស្ថានភាពជានិស្សិត:", ជាសិស្ស)
បង្ហាញ("ការងារបច្ចុប្បន្ន:", ការងារ)

សញ្ញាវណ្ណយុត្តិ & បញ្ចប់បន្ទាត់ (Punctuations) #

ខ្មែរចារ (KhmerChar) បត់បែនតាមរចនាប័ទ្មខ្មែរ ដោយអនុញ្ញាតឱ្យប្រើសញ្ញាវណ្ណយុត្តិខ្មែរសម្រាប់បញ្ចប់ប្រយោគ ឬកំណត់លក្ខខណ្ឌ៖

Getter និង Setter (`យក` & `ដាក់` / `កំណត់`) #

ខ្មែរចារ (KhmerChar) គាំទ្រការបង្កើត Getter ដោយប្រើពាក្យគន្លឹះ យក (ឬ get) និង Setter ដោយប្រើពាក្យគន្លឹះ ដាក់ ឬ កំណត់ (ឬ set) ដើម្បីគ្រប់គ្រង និងការពារទិន្នន័យ (Encapsulation / Computed Properties) ក្នុង Object៖

KHMERgetter_setter.khmer
ថ្នាក់ រង្វង់ {
    បង្កើត(កាំ) {
        នេះ._កាំ = កាំ
    }

    # Getter: ចូលប្រើប្រាស់ដូច Property
    យក កាំ {
        ត្រឡប់ នេះ._កាំ
    }

    # Setter: ហៅដោយស្វ័យប្រវត្តិតាមរយៈ Assignment
    ដាក់ កាំ(តម្លៃថ្មី) {
        បើ (តម្លៃថ្មី > ០) {
            នេះ._កាំ = តម្លៃថ្មី
        } ផ្សេងទៀត {
            បង្ហាញ("កំហុស: កាំត្រូវតែធំជាង ០!")
        }
    }

    # Computed Property Getter
    យក ផ្ទៃក្រឡា {
        ត្រឡប់ ៣.១៤ * នេះ._កាំ * នេះ._កាំ
    }
}

បង្ហាញ("ផ្ទៃក្រឡា:", c.ផ្ទៃក្រឡា)

c.កាំ = ១០
បង្ហាញ("កាំថ្មី:", c.កាំ)
បង្ហាញ("ផ្ទៃក្រឡាថ្មី:", c.ផ្ទៃក្រឡា)

អនុគមន៍ស្ដង់ដារ (Built-in Functions) #

ខ្មែរចារ (KhmerChar) ផ្ដល់នូវអនុគមន៍ស្ដង់ដារដែលភ្ជាប់មកស្រាប់ជាមួយភាសា៖

អនុគមន៍ (Builtin) ឈ្មោះអង់គ្លេស (Alias) ការប្រើប្រាស់ (Usage) ការពន្យល់ (Explanation)
បង្ហាញ(...) print(...) បង្ហាញ("តម្លៃ:", x) បង្ហាញអត្ថបទ ឬតម្លៃអថេរនៅលើស្ថានីយ (Standard Output)
ប្រវែង(...) len(...) ប្រវែង("កម្ពុជា") គណនាប្រវែងតួអក្សរ ឬចំនួនធាតុក្នុង Array/Map
ប្រភេទ(...) type(...) ប្រភេទ(១២៣) កំណត់ប្រភេទតម្លៃ (លេខ, អក្សរ, តក្កវិទ្យា, បញ្ជី, វត្ថុ, ថ្នាក់, etc.)
ដាច់ខាត(...) abs(...) ដាច់ខាត(-១០) តម្លៃដាច់ខាតនៃលេខ (Absolute value)
ឬសការ៉េ(...) sqrt(...) ឬសការ៉េ(២៥) រកឬសការ៉េនៃលេខ (Square root)
ស្វ័យគុណ(...) pow(...) ស្វ័យគុណ(២, ៣) គណនាស្វ័យគុណ (២^៣ = ៨)
បង្គត់(...) round(...) បង្គត់(៤.៧) បង្គត់រកចំនួនគត់ជិតបំផុត (Round to nearest integer)
បង្គត់ចុះ(...) floor(...) បង្គត់ចុះ(៤.៩) បង្គត់ទម្លាក់ចុះក្រោម (Floor)
បង្គត់ឡើង(...) ceil(...) បង្គត់ឡើង(៤.១) បង្គត់រុញឡើងលើ (Ceiling)
អតិបរមា(...) max(...) អតិបរមា(១០, ២០, ៥) រកតម្លៃធំបំផុត អាចប្រើជាមួយអាគុយម៉ង់ ឬបញ្ជី
អប្បបរមា(...) min(...) អប្បបរមា(១០, ២០, ៥) រកតម្លៃតូចបំផុត អាចប្រើជាមួយអាគុយម៉ង់ ឬបញ្ជី
ចៃដន្យ(...) random(...) ចៃដន្យ(១, ១០) បង្កើតលេខចៃដន្យ (Random number between min and max)
ជាលេខ(...) toNum / toInt ជាលេខ("១២៣") បម្លែងទៅជាលេខ គាំទ្រទាំងលេខខ្មែរ និងអារ៉ាប់
ជាអក្សរ(...) toStr(...) ជាអក្សរ(៧៨៩) បម្លែងតម្លៃទៅជាអត្ថបទ String
ជាតក្ក(...) toBool(...) ជាតក្ក(១) បម្លែងតម្លៃទៅជាតក្កវិទ្យា Boolean (ពិត / មិនពិត)
ពុះ(...) split(...) ពុះ("ក ខ គ", " ") បំបែកអត្ថបទទៅជាបញ្ជី Array
កាត់(...) substr(...) កាត់("សួស្តី", ០, ៤) កាត់យកផ្នែកនៃអត្ថបទតាមសន្ទស្សន៍ចាប់ផ្តើម និងបញ្ចប់
ជំនួស(...) replace(...) ជំនួស(str, "ចាស់", "ថ្មី") ជំនួសពាក្យចាស់ដោយពាក្យថ្មីក្នុងអត្ថបទ
សម្អាត(...) trim(...) សម្អាត(" អត្ថបទ ") លុបចន្លោះទទេ (Whitespace) ខាងដើម និងខាងចុង
អក្សរធំ(...) upper(...) អក្សរធំ("hello") បម្លែងអក្សរទាំងអស់ទៅជាអក្សរធំ
អក្សរតូច(...) lower(...) អក្សរតូច("HELLO") បម្លែងអក្សរទាំងអស់ទៅជាអក្សរតូច
បន្ថែម(...) append(...) បន្ថែម(បញ្ជី, ធាតុ) បន្ថែមធាតុថ្មីទៅចុងបញ្ចប់នៃបញ្ជី Array
បញ្ចូល(...) insert(...) បញ្ចូល(បញ្ជី, ០, ធាតុ) បញ្ចូលធាតុនៅទីតាំងកំណត់ក្នុងបញ្ជី
ដកចេញ(...) pop(...) ដកចេញ(បញ្ជី, [ទីតាំង]) ដកធាតុចុងក្រោយ ឬតាមទីតាំងដែលបានបញ្ជាក់
លុប(...) remove(...) លុប(បញ្ជី, ធាតុ) លុបធាតុដែលមានតម្លៃត្រូវគ្នាចេញពីបញ្ជី
ភ្ជាប់(...) join(...) ភ្ជាប់(បញ្ជី, "-") ភ្ជាប់ធាតុទាំងអស់ក្នុងបញ្ជីជាអត្ថបទ String តែមួយ
តម្រៀប(...) sort(...) តម្រៀប(បញ្ជី) តម្រៀបធាតុក្នុងបញ្ជីតាមលំដាប់លេខ ឬអក្ខរក្រម
ត្រឡប់បញ្ជី(...) reverse(...) ត្រឡប់បញ្ជី(បញ្ជី) ត្រឡប់បញ្ជី ឬអក្សរពីក្រោយមកមុខ (Reverse)
ស្វែងរក(...) indexOf(...) ស្វែងរក(បញ្ជី, ធាតុ) រកសន្ទស្សន៍ (Index) នៃធាតុ ឬអក្សរ (ផ្ដល់ -១ បើគ្មាន)
មាន(...) contains(...) មាន(បញ្ជី, ធាតុ) ពិនិត្យវត្តមានធាតុក្នុងបញ្ជី អត្ថបទ ឬវត្ថុ (ពិត / មិនពិត)
ពេលនេះ() now() ពេលនេះ() ផ្ដល់ពេលវេលាបច្ចុប្បន្នគិតជា Milliseconds ចាប់ពី Epoch
អាន(...) input(...) អាន("បញ្ចូលឈ្មោះ: ") ទទួលការវាយបញ្ចូលពីអ្នកប្រើប្រាស់ (Standard Input)

ឧបករណ៍អភិវឌ្ឍន៍ (Tools & IDEs) #

ដើម្បីសម្រួលដល់ការសរសេរកូដ ប្រព័ន្ធអេកូឡូស៊ី ខ្មែរចារ (KhmerChar) រួមមានឧបករណ៍ទំនើបៗជាច្រើន៖

  • ខ្មែរចារ Khmer IDE (Cross-Platform)៖ កម្មវិធីសរសេរកូដបង្កើតឡើងដោយ Flutter មានម៉ាស៊ីន Dart Engine ក្នុងស្រុក គាំទ្រការសរសេរលើ macOS, Windows, Linux និង Web ដោយផ្ទាល់ ជាមួយ Virtual Khmer Keyboard, Tabs, AST Inspector និង Output Console។
  • Programiz-Style Web IDE៖ កម្មវិធីសរសេរកូដរចនាប័ទ្ម Programiz ដំណើរការលើ Web Browser ជាមួយ Python Backend Server។
  • Command Line Interface (CLI) & REPL៖ ឧបករណ៍បញ្ជាផ្ទាល់តាមរយៈ Terminal សម្រាប់រ៉ាន់ឯកសារ .khmer។

តារាងសង្ខេបពាក្យគន្លឹះ (Khmer Syntax Cheat Sheet) #

តារាងយោងសម្រាប់ពាក្យគន្លឹះទាំងអស់នៅក្នុង ខ្មែរចារ (KhmerChar)៖

ពាក្យគន្លឹះ (Keyword) សមមូលអង់គ្លេស (Equivalent) អត្ថន័យ និងការប្រើប្រាស់ ឧទាហរណ៍កូដ
តាំង let / var ប្រកាសអថេរថ្មី តាំង x = ១០;
បង្ហាញ print / echo បង្ហាញលទ្ធផលលើអេក្រង់ បង្ហាញ("សួស្តី");
បើ if លក្ខខណ្ឌផ្ទៀងផ្ទាត់ដំបូង បើ (x > ០) { ... }
ឬបើ else if / elif លក្ខខណ្ឌបន្ទាប់ ឬបើ (x == ០) { ... }
ផ្សេងទៀត else លក្ខខណ្ឌក្រៅពីនេះ ផ្សេងទៀត { ... }
ខណៈ while រង្វិលជុំផ្ទៀងផ្ទាត់លក្ខខណ្ឌ ខណៈ (x > ០) { ... }
សម្រាប់ for រង្វិលជុំមានចំនួនជុំកំណត់ សម្រាប់ (តាំង i=០; i<៥; i=i+១)
អនុគមន៍ function / method ប្រកាសអនុគមន៍ទូទៅ ឬវិធីសាស្ត្រក្នុងថ្នាក់ អនុគមន៍ បូក(ក, ខ) { ... }
ត្រឡប់ return បញ្ជូនតម្លៃត្រឡប់ពីអនុគមន៍ ត្រឡប់ ក + ខ
ថ្នាក់ class ប្រកាសថ្នាក់ OOP ថ្នាក់ សិស្ស { ... }
បង្កើត constructor / __init__ វិធីសាស្ត្រចាប់ផ្ដើមបង្កើតវត្ថុ បង្កើត(ឈ្មោះ) { នេះ.ឈ្មោះ = ឈ្មោះ }
នេះ / ខ្លួនវា this / self យោងទៅលើ Object បច្ចុប្បន្ន នេះ.ឈ្មោះ = "វ៉េងឈួង"
ថ្មី new បង្កើត Instance ថ្មីនៃថ្នាក់ តាំង p = ថ្មី សិស្ស("តារា")
បន្តពី extends បន្តវេនពីថ្នាក់មេ (Inheritance) ថ្នាក់ ឆ្មា បន្តពី សត្វ
យក get ប្រកាស Getter សម្រាប់ទាញយកតម្លៃគុណលក្ខណៈ យក ឈ្មោះពេញ { ... }
ដាក់ / កំណត់ set ប្រកាស Setter សម្រាប់កំណត់តម្លៃគុណលក្ខណៈ ដាក់ អាយុ(ត) { នេះ._អាយុ = ត; }
ពិត true តម្លៃប៊ូលីនពិត តាំង ត្រូវ = ពិត
មិនពិត false តម្លៃប៊ូលីនមិនពិត តាំង ខុស = មិនពិត
ទទេ null / none តម្លៃទទេគ្មានទិន្នន័យ តាំង ទិន្នន័យ = ទទេ
