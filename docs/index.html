ឯកសារណែនាំផ្លូវការ — ភាសាខ្មែរ (KhmerLang)

KhmerLang (ភាសាខ្មែរ) គឺជាភាសាប្រូក្រាមីងកម្រិតខ្ពស់ដែលត្រូវបានរចនាឡើងជាមួយវាក្យសព្ទ និងពាក្យគន្លឹះជាភាសាខ្មែរពិតប្រាកដ។ វាផ្ដល់នូវភាពងាយស្រួលក្នុងការសិក្សា សរសេរកូដតាមបែប Object-Oriented Programming (OOP) និងគាំទ្រលេខខ្មែរ (០-៩) ដោយផ្ទាល់។

🚀 ចាប់ផ្តើមរៀនឥឡូវនេះ 🎮 សាកល្បងកូដលើ Web Browser

សេចក្តីផ្តើម (Introduction) #

ភាសាខ្មែរ (KhmerLang) ត្រូវបានបង្កើតឡើងដើម្បីកាត់បន្ថយរបាំងភាសាក្នុងវិស័យវិទ្យាសាស្ត្រកុំព្យូទ័រនៅកម្ពុជា។ សិស្ស និស្សិត និងអ្នករៀនដំបូងអាចយល់ច្បាស់អំពីតក្កវិជ្ជានៃកូដ (Logic) តាមរយៈការប្រើពាក្យខ្មែរធម្មជាតិ ដូចជា តាំង, បង្ហាញ, បើ, ខណៈ, ថ្នាក់ និង អនុគមន៍។

💡
ចំណុចពិសេស៖ រាល់កូដឧទាហរណ៍ទាំងអស់ក្នុងឯកសារនេះ អ្នកអាចចុចប៊ូតុង ▷ រ៉ាន់កូដ (Run) ដើម្បីដំណើរការកូដ និងទស្សនាលទ្ធផលជាក់ស្ដែងលើ Browser បានភ្លាមៗដោយមិនបាច់ដំឡើងអ្វីទាំងអស់!

ការដំឡើង & ការចាប់ផ្តើម (Installation & Setup) #

ការចាប់ផ្តើមសរសេរកូដជាមួយ KhmerLang (ភាសាខ្មែរ) មានភាពងាយស្រួល និងរហ័ស។ អ្នកប្រើប្រាស់អាចជ្រើសរើសការដំឡើងតាមរយៈ Command Line Tool (CLI) សម្រាប់ដំណើរការលើម៉ាស៊ីនផ្ទាល់ ឬប្រើប្រាស់កម្មវិធី Khmer IDE ដោយមិនចាំបាច់ដំឡើងអ្វីទាំងអស់។

១. តម្រូវការប្រព័ន្ធ (Prerequisites)

មុនពេលចាប់ផ្តើមដំឡើង សូមប្រាកដថាម៉ាស៊ីនរបស់អ្នកមានលក្ខខណ្ឌដូចខាងក្រោម៖

  • ប្រព័ន្ធប្រតិបត្តិការ៖ គាំទ្រ macOS, Linux, និង Windows (WSL / PowerShell)
  • Python 3.8 ឬខ្ពស់ជាងនេះ៖ សម្រាប់ដំណើរការ Interpreter ដើមរបស់ភាសា
  • Git៖ សម្រាប់ទាញយកប្រភពកូដ ឬ Releases

២. ការដំឡើង CLI សម្រាប់អ្នកប្រើប្រាស់ទូទៅ (Universal One-Line Install)

អ្នកប្រើប្រាស់គ្រប់រូបអាចដំឡើង khmer CLI លើម៉ាស៊ីនរបស់ខ្លួនដោយផ្ទាល់តាមរយៈពាក្យបញ្ជាតែមួយបន្ទាត់៖

អថេរ និងប្រភេទតម្លៃ (Variables & Data Types) #

នៅក្នុងភាសាខ្មែរ យើងប្រើពាក្យគន្លឹះ តាំង (Let) ដើម្បីប្រកាសអថេរ។ អថេរក្នុង KhmerLang គឺ dynamic-typed មានន័យថាអ្នកអាចផ្ទុកទិន្នន័យជា លេខ, អក្សរ (String), Boolean, ឬ Null បានដោយសេរី។

  • លេខ (Numbers): គាំទ្រទាំងលេខអារ៉ាប់ (10, 3.14) និងលេខខ្មែរ (១០, ៣.១៤)។
  • អក្សរ (Strings): សរសេរនៅចន្លោះសញ្ញាសម្រង់ "..." ឬ '...'។
  • ប៊ូលីន (Booleans): ប្រើពាក្យគន្លឹះ ពិត (True) និង មិនពិត (False)។
  • ទទេ (Null): ប្រើពាក្យគន្លឹះ ទទេ សម្រាប់តម្លៃដែលគ្មានទិន្នន័យ។
KHMER variables.khmer 
# ប្រកាសអថេរផ្សេងៗ
តាំង ឈ្មោះ = "វ៉េងឈួង"
តាំង អាយុ = ២១
តាំង ជាសិស្ស = ពិត
តាំង ការងារ = ទទេ

បង្ហាញ("ឈ្មោះ:", ឈ្មោះ)
បង្ហាញ("អាយុ:", អាយុ)
បង្ហាញ("ស្ថានភាពជានិស្សិត:", ជាសិស្ស)
បង្ហាញ("ការងារបច្ចុប្បន្ន:", ការងារ)

សម្រាប់ for រង្វិលជុំមានចំនួនជុំកំណត់ សម្រាប់ (តាំង i=០; i<៥; i=i+១)
អនុគមន៍ / វិធី function / def ប្រកាសអនុគមន៍ ឬវិធីសាស្ត្រ អនុគមន៍ បូក(ក, ខ) { ... }
ត្រឡប់ return បញ្ជូនតម្លៃត្រឡប់ពីអនុគមន៍ ត្រឡប់ ក + ខ
ថ្នាក់ class ប្រកាសថ្នាក់ OOP ថ្នាក់ សិស្ស { ... }
បង្កើត constructor / __init__ វិធីសាស្ត្រចាប់ផ្ដើមបង្កើតវត្ថុ បង្កើត(ឈ្មោះ) { នេះ.ឈ្មោះ = ឈ្មោះ }
នេះ / ខ្លួនវា this / self យោងទៅលើ Object បច្ចុប្បន្ន នេះ.ឈ្មោះ = "វ៉េងឈួង"
ថ្មី new បង្កើត Instance ថ្មីនៃថ្នាក់ តាំង p = ថ្មី សិស្ស("តារា")
បន្តពី extends បន្តវេនពីថ្នាក់មេ (Inheritance) ថ្នាក់ ឆ្មា បន្តពី សត្វ
ពិត true តម្លៃប៊ូលីនពិត តាំង ត្រូវ = ពិត

ទទេ null / none តម្លៃទទេគ្មានទិន្នន័យ តាំង ទិន្នន័យ = ទទេ
